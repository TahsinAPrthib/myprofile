# Public Folder

Put your profile picture here!

## How to add your picture:

1. Save your profile picture as `profile.jpg` in this folder
2. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`
3. Recommended size: 400x400 pixels or larger (square image works best)
4. The image will automatically appear in:
   - Hero section (circular, at the top)
   - About section (rectangular, on the left)

## Alternative: Use a different filename

If your image has a different name, update these files:
- `components/Hero.tsx` - line 24: change `src="/profile.jpg"` to your filename
- `components/About.tsx` - line 33: change `src="/profile.jpg"` to your filename

Example: If your file is `my-photo.png`, change to `src="/my-photo.png"`
